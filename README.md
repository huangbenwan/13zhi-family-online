
# 五人十三支線上版（第一個多人原型）

這是一個給家人同樂的瀏覽器多人原型，不包含現金下注或金流。

## 已包含
- 最多 5 人房間
- 房號建立 / 加入
- 65 張特殊牌組：♠×2、♥×1、♦×1、♣×1
- 每人 13 張
- 頭 3 / 中 5 / 尾 5
- 你目前確認的 11 種牌型與牌力
- A2345 為最小順、10JQKA 為最大順
- 不比較花色大小
- 倒水：牌力必須 尾 > 中 > 頭
- 兩人比較：頭、中、尾三墩全部勝出才得 100 戰績分；否則該對戰 0/0
- 伺服器負責洗牌、發牌、驗證提交與計分

## 本機測試
需要 Node.js 18+。

```bash
npm install
npm start
```

然後開啟：
http://localhost:3000

同一個區域網路的家人可以用「主機電腦的區網 IP:3000」測試，例如：
http://192.168.1.20:3000

## 真正讓外部家人連線
需要把這個 Node.js 專案部署到支援 WebSocket 的主機，例如 Render、Railway、Fly.io 或自己的 VPS。
部署完成後會得到一個 HTTPS 網址，5 個家人直接用手機瀏覽器開同一個網址，再輸入房號即可。
